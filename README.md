# 🎓 E-Learning Platform

A responsive E-Learning Platform developed using React.js that provides an interactive interface for exploring, filtering, and viewing online courses. The project focuses on component-based development, API integration, responsive design, and a clean user experience.

## 📌 About the Project

The E-Learning Platform is a frontend web application designed to make online course discovery simple and organized. Users can browse different courses, filter courses based on categories, and interact with course cards through a responsive interface.

## ✨ Features

- 📚 Display online courses
- 🔍 Filter courses by category
- 🃏 Reusable course card components
- ❤️ Like/interaction functionality
- ⏳ Loading spinner while fetching data
- 🌐 API integration for course data
- 📱 Responsive design for different screen sizes
- 🧩 Component-based React architecture
- 🎨 Clean and user-friendly interface
